# Customer Segmentation using K-Means Clustering

## Overview
This project uses Machine Learning (K-Means Clustering) to segment mall customers based on:

- Age
- Annual Income
- Spending Score

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Features
- Elbow Method
- K-Means Clustering
- 2D & 3D Visualization
- Customer Insights Dashboard

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
